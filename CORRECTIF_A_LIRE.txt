MA CAVE V1.2.1 MOBILE — CORRECTIF DU DEPOT

DIAGNOSTIC DU ZIP FOURNI :
- manifest.json absent : le nouveau service worker ne pouvait pas finir son installation.
- js/database.js, js/exports.js et js/ui.js étaient issus de la version OneDrive.
- Le navigateur montrait encore l’interface OneDrive V1.1 provenant du cache.

INSTALLATION :
1. Décompresse ce ZIP.
2. Dans GitHub > Code > Add file > Upload files, fais glisser TOUT LE CONTENU de ce ZIP, y compris le dossier js, à la racine du dépôt. Ne crée pas de sous-dossier supplémentaire. Valide le commit.
3. Attends la fin du déploiement GitHub Pages.
4. Sur chaque appareil ayant déjà ouvert l’ancienne version, ouvre :
   https://sergecrocilli-sys.github.io/MA-CAVE-A-VIN/reparer.html
5. Appuie sur Charger la version mobile. Le cache de Ma Cave est actualisé ; IndexedDB n’est pas effacé.
6. L’accueil doit indiquer V1.2.1 Mobile, sans connexion Microsoft.

Ce correctif contient uniquement les fichiers à ajouter/remplacer et ces instructions. Les autres fichiers du dépôt restent nécessaires.
Ne vide pas les données du navigateur. Les fiches et photos de la cave locale sont conservées.
Aucun accès OneDrive ou Supabase n’est utilisé dans cette version.
